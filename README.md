# GetOrganized 📋✨

GetOrganized es una aplicación web de gestión de tareas colaborativa diseñada con un enfoque prioritario en la experiencia de usuario (UX) y el diseño responsive. Permite a equipos y clientes organizar flujos de trabajo mediante un tablero Kanban interactivo y una vista de lista filtrable.

## 🚀 Características Principales

- **Doble Vista de Trabajo:** Alternancia fluida entre Tablero Kanban (Drag & Drop) y Vista de Lista.
- **Sistema de Colaboración:** Gestión de equipos con capacidad para invitar y revocar accesos a clientes o compañeros en proyectos específicos.
- **Autenticación de Usuarios:** Sistema de login y registro con validación de credenciales.
- **Filtros de Prioridad:** Etiquetado visual (Alta, Media, Baja) y filtrado instantáneo en la vista de lista.
- **Diseño Responsive:** Interfaz adaptada a dispositivos móviles con menús compactos y scroll optimizado, simulando la experiencia de una app nativa.
- **Branding Customizado:** Implementación de logotipo en SVG por código y paleta de colores coherente.

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5, CSS3 (Flexbox/Grid, Media Queries), Vanilla JavaScript (ES6+).
- **Backend (Mock):** `json-server` para simular una API REST completa y gestionar la base de datos `db.json`.
- **Librerías Extra:** `SortableJS` para la lógica de arrastrar y soltar (Drag & Drop).
